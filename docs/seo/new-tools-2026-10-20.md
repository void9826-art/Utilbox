# New tools — 2026-10-20 (cloud session)

23 new tools, taking the site from 131 to 154. Every one of them runs entirely in the browser (`processing: "client"`): nothing is uploaded, and none of them calls this site's server or a third-party API. Each has an answer-first intro of 48–60 words, a how-to, a how-it-works section stating the method or formula, six FAQs (four main and two extra), tips, and unit-tested logic in `src/lib/`. Every worked example on these pages is also checked against the code in `scripts/verify-examples.mjs`.
